# ES File Manager

مدير ملفات عملي لنظام Android لتنظيم الملفات والتطبيقات والوصول إلى المحتوى المحلي والبعيد من واجهة واحدة.

## نظرة عامة

يساعدك **ES File Manager** على إدارة الملفات والمجلدات الموجودة على جهاز Android بسهولة، بدءًا من التصفح والبحث، وصولًا إلى النسخ والنقل وإعادة التسمية والحذف والمشاركة. كما يتيح التعامل مع الملفات المضغوطة، وإدارة التطبيقات، والاتصال بمصادر تخزين وأجهزة أخرى عند الحاجة.

يهدف التطبيق إلى جمع المهام اليومية الخاصة بالملفات في مكان واحد، بحيث لا يحتاج المستخدم إلى التبديل بين عدة أدوات للوصول إلى ملف أو تنظيم مجلد أو مشاركة محتوى.

## الميزات الأساسية

- تصفح الملفات والمجلدات على مساحة التخزين المحلية.
- إنشاء الملفات والمجلدات وإعادة تسميتها ونسخها ونقلها وحذفها.
- البحث عن الملفات، مع خيارات للبحث المتقدم ومطابقة المحتوى.
- فرز العناصر حسب الاسم أو الحجم أو تاريخ التعديل، مع إمكانية وضع المجلدات أو الملفات في المقدمة.
- الوصول السريع إلى الملفات الحديثة وسجل التصفح والعلامات المرجعية.
- إظهار الملفات والمجلدات المخفية عند الحاجة.
- ضغط الملفات واستخراجها، بما في ذلك صيغ أرشيف شائعة مثل ZIP و7z وRAR وGZIP وBZIP2 وXZ.
- فتح الملفات باستخدام التطبيقات المناسبة ومشاركة الملفات مع التطبيقات الأخرى.
- عرض خصائص الملفات والمجلدات وتحرير الملفات النصية.
- تصفح وإدارة التطبيقات المثبتة، بما في ذلك فتح التطبيق أو إنشاء نسخة احتياطية منه أو إلغاء تثبيته وفق صلاحيات النظام.
- تشفير الملفات والمجلدات وفك تشفيرها باستخدام كلمة مرور رئيسية، مع دعم المصادقة بالبصمة على الأجهزة المتوافقة.
- الاتصال بالمجلدات المشتركة عبر SMB، وبالأجهزة أو الخوادم عبر SCP/SFTP.
- الوصول إلى خدمات التخزين السحابي المدعومة، مثل Google Drive وDropbox وOneDrive وBox، عبر إضافة Amaze Cloud عند توفرها.
- تشغيل خادم FTP على الجهاز لمشاركة الملفات عبر الشبكة المحلية.
- تخصيص المظهر، بما في ذلك السمات الفاتحة والداكنة وسمة OLED وبعض ألوان الواجهة.
- دعم الأجهزة التي تستخدم صلاحيات الجذر عند تفعيل الوضع المناسب وبحذر.

## من سيستخدم التطبيق ولماذا

- **مستخدمو Android اليوميون:** لتنظيم الصور والمستندات والتنزيلات وبقية الملفات من مكان واحد.
- **الطلاب والموظفون:** للوصول السريع إلى الملفات، وإعادة ترتيبها، وضغطها أو مشاركتها.
- **مديرو الأجهزة والمستخدمون المتقدمون:** لإدارة التطبيقات والملفات المخفية والاتصالات الشبكية.
- **من يتعاملون مع أجهزة متعددة:** لنقل الملفات عبر FTP أو SMB أو SCP/SFTP أو خدمات التخزين السحابي المدعومة.

## لمحة عن التقنيات والأدوات المستخدمة

- تطبيق Android مبني باستخدام Java وGradle.
- يعتمد على Android SDK وAndroidX وMaterial Design لبناء الواجهة وتجربة الاستخدام.
- يستخدم Room لتخزين بيانات التطبيق مثل السجل والعلامات المرجعية والتبويبات.
- يستخدم Glide للتعامل مع صور ومعاينات الملفات.
- يتضمن دعمًا للاتصالات عبر SSH/SFTP وSMB وخادم FTP.
- يستفيد من Apache Commons Compress للتعامل مع صيغ الضغط والأرشفة، بما في ذلك 7z.
- يتضمن نسختي بناء مخصصتين لـ F-Droid وGoogle Play.

## تعليمات استخدام وسيناريوهات موجزة

### تنظيم ملف أو مجلد

1. افتح التطبيق وانتقل إلى المجلد المطلوب.
2. حدّد الملف أو المجلد المراد التعامل معه.
3. اختر الإجراء المناسب: نسخ، نقل، إعادة تسمية، حذف، مشاركة، أو إضافة إلى العلامات المرجعية.

### العثور على ملف

1. افتح أداة البحث من الواجهة الرئيسية.
2. أدخل اسم الملف أو جزءًا منه.
3. استخدم البحث المتقدم عند الحاجة إلى البحث داخل المحتوى أو استخدام نمط بحث أكثر تحديدًا.

### ضغط الملفات أو استخراجها

1. حدّد ملفًا أو أكثر.
2. اختر **ضغط** لإنشاء أرشيف، أو افتح أرشيفًا موجودًا واختر **استخراج**.
3. حدّد اسم الأرشيف أو مجلد الاستخراج، ثم أكّد العملية.

### مشاركة الملفات عبر الشبكة

1. تأكد من اتصال الجهاز بالشبكة المناسبة.
2. افتح إعدادات خادم FTP وابدأ الخادم.
3. استخدم العنوان والمنفذ الظاهرين للوصول إلى الملفات من جهاز آخر على الشبكة نفسها.

### استخدام التخزين السحابي أو الاتصال البعيد

1. أضف اتصالًا سحابيًا أو اتصال SMB أو SCP/SFTP من قائمة الاتصالات.
2. أدخل بيانات الاتصال المطلوبة.
3. تصفح الملفات البعيدة ونفّذ العمليات التي يسمح بها المصدر المتصل.

## متطلبات خاصة

- يعمل التطبيق على أجهزة Android التي تدعم الحد الأدنى المحدد في المشروع، وهو Android 4.1 أو أحدث.
- يلزم منح التطبيق صلاحية الوصول إلى مساحة التخزين حتى يتمكن من قراءة الملفات وإدارتها.
- تتطلب ميزات الشبكة اتصالًا مناسبًا بالشبكة، وقد تتطلب بعض الاتصالات بيانات اعتماد صحيحة أو إعدادات مشاركة مفعّلة على الخادم.
- يتطلب الوصول إلى التخزين السحابي تثبيت إضافة Amaze Cloud عند استخدام هذه الميزة.
- لا يتوفر وضع الجذر إلا على جهاز مهيأ بصلاحيات Root، وينبغي تفعيله فقط للمستخدمين الذين يفهمون آثاره.
- قد تتطلب إدارة التطبيقات أو حذفها أو تثبيت حزم APK تأكيدات وصلاحيات إضافية من Android.
