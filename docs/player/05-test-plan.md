## 2. ما هو منفَّذ الآن (13 صنفًا، 127 دالة اختبار)

| الصنف | يغطي | أمثلة على الحالات الحدية |
| --- | --- | --- |
| `PlaybackStateMachineTest` | الانتقالات القانونية، رفض القفزات، استعادة الحالة بعد التجويع، خطأ→IDLE | `ENDED → PLAYING` مرفوض؛ `PAUSED` لا يُستأنف تلقائيًا بعد تجويع |
| `MediaQueueTest` | التالي/السابق، التكرار، الخلط، الاستقرار بنفس البذرة | طابور بعنصر واحد لا يدور؛ الخلط لا يغيّر العنصر الحالي |
| `AbRepeatControllerTest` | A/B، التبديل عند B<A، الإلغاء، التقدّم داخل الحلقة | نقل A بعد B يُلغي الحلقة |
| `SpeedControllerTest` | الالتقاط إلى القوالب، الحدّ، الدوران، التسميات | 1.13× تُحترم كما هي؛ الالتفاف من 1× للخلف |
| `FrameStepPlannerTest` | مدة الإطار، المحاذاة، الحدود، 23.976/25/30/50/60 fps | لا قيم سالبة؛ التقدّم يُحدّ بالمدة |
| `ResumePolicyTest` | عتبة 5 ث، ذيل 30 ث، نسبة 95%، مدة مجهولة | ملف 100 دقيقة عند 90 دقيقة = استئناف |
| `PlaybackTuningTest` | تصنيف الفئة، حدود المخازن، سقف الدقة، الخيوط، الموسّعات | API 19 = فئة منخفضة دائمًا |
| `DecoderPolicyTest` | كل فروع السياسة، DRM بلا رجوع برمجي، أسباب القرارات | `drm_no_secure_path`؛ HEVC بلا عتاد = مرفوض |
| `CacheIndexTest` | LRU بالبايتات، الإخلاء المتعدد، رفض ما يفوق السعة، التحديث | كائن أكبر من السعة يُرفض دون إخلاء |
| `GestureEngineTest` | العتبة، قفل المحور، الدلتات التراكمية-بين-الأحداث، المناطق، القفل | سحب مائل يبقى تخطيًا؛ الدلتا الثانية = الأولى |
| `PlaybackMetricsTest` | TTFF، التقطيع، نسبة التقطيع، زمن المشاهدة، الساقطة، كمون القفز، البت الموزون | القفز للخلف لا يُحتسب زمن مشاهدة |
| `TelemetrySinkTest` | الدفعات، التفريغ الجزئي، الحدّ، JSON مع تهريب | `\"` و`\` و`\n` تُهرَّب |
| `SubtitleStyleTest` + ضريبة الأخطاء | الحدود، الخطوات، الإزاحة، نسخ كل الحقول، تصنيف الأخطاء | 10 خطوات لا تتجاوز 12% |

## 5. قائمة تحقق يدوية سريعة (10 دقائق)

1. افتح ملفًا > 1 دقيقة → أغلقه بعد 30 ثانية → أعد فتحه: يظهر حوار الاستئناف.
2. افتح ملفًا وشاهده حتى آخر 20 ثانية → أعد فتحه: يبدأ من الصفر بلا حوار.
3. اسحب رأسيًا على اليسار بسرعة: السطوع يتغير تدريجيًا ولا يقفز إلى 0 أو 100.
4. ابدأ سحبًا أفقيًا ثم انحرف رأسيًا: يبقى تخطيًا.
5. اضبط A-B وشغّل: يعود إلى A بدقة الإطار.
6. غيّر السرعة إلى 2×: الصوت يبقى مفهومًا (تصحيح الطبقة).
7. اضغط Home أثناء التشغيل: PiP يستمر.
8. افتح `⋮ → إحصاءات التشغيل`: TTFF < 400 مللي ثانية على جهاز متوسط.
