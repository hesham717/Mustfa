# 02 — المواصفة الوظيفية وتجربة الاستخدام

## 1. نطاق الشاشة

شاشة واحدة بملء الشاشة (`VideoPlayerActivity`) تُفتح من مدير الملفات لأي عنصر
`Icons.VIDEO`، محليًا (`file://`، `content://`) أو عبر الشبكة. ثلاثة أوضاع عرض:
ملء الشاشة العادي، ملء الشاشة الغامر، و«صورة داخل صورة».

## 2. خريطة التفاعل

```
┌──────────────────────────────────────────────────────────────────────┐
│  [×]  عنوان الملف                                        [🔒] [⋮]   │  شريط علوي
│                                                                      │
│                                                                      │
│      النقر المزدوج:          النقر المزدوج:                          │
│      رجوع 10 ث               تقديم 10 ث                              │
│  ┌───────────────┐    ┌──────────────┐    ┌───────────────┐         │
│  │               │    │  نقر مفرد =  │    │               │         │
│  │  سحب رأسي =   │    │  إظهار/إخفاء │    │  سحب رأسي =   │         │
│  │  السطوع       │    │   الضوابط    │    │   الصوت       │         │
│  └───────────────┘    └──────────────┘    └───────────────┘         │
│            ◀────── سحب أفقي = شريط زمني حي ──────▶                   │
│                                                                      │
│   [⏮] [⏪]  ( ▶ / ⏸ )  [⏩] [⏭]                                      │  وسط
│                                                                      │
│  00:12 ─────────────●──────────────────────────── 41:07             │
│  [الصوت] [الترجمة] [1x]                        [Fit] [⛶]           │  سفلي
└──────────────────────────────────────────────────────────────────────┘
```

قائمة `⋮`: معلومات الفيديو · إحصاءات التشغيل · تكرار A-B · إطار سابق · إطار تالٍ ·
وضع التكرار · صورة داخل صورة · تشغيل التالي تلقائيًا · قفل/فك اتجاه الشاشة.

## 3. متطلبات النقل (Transport)

| # | المتطلب | السلوك | الحالة |
| --- | --- | --- | --- |
| T1 | تشغيل/إيقاف | نقر مفرد في المنتصف أو زر ▶ | منفَّذ |
| T2 | تقديم/إرجاع بخطوة | خطوة قابلة للضبط 5/10/15/30 ث (`video_seek_seconds`) | منفَّذ |
| T3 | شريط زمني حي | سحب أفقي يعرض `±Δ` والزمن المستهدف، ويقفز عند الإفلات | منفَّذ |
| T4 | التالي/السابق | عبر `MediaQueue`، يحترم وضع التكرار | منفَّذ |
| T5 | سرعة التشغيل | 0.5×–2× على كل الأجهزة، حتى 4× على الفئة العليا، مع تصحيح الطبقة الصوتية | منفَّذ |
| T6 | تكرار A-B | ضغطة = A، ثانية = B، ثالثة = إلغاء | منفَّذ |
| T7 | خطوة إطار | للأمام عبر `stepForward()`، للخلف ببحث إلى حد الإطار السابق | منفَّذ |
| T8 | الاستئناف | حوار «المتابعة من mm:ss؟» إن كان المحفوظ > 5 ث | منفَّذ |

| T10 | وضع التكرار | OFF → ALL → ONE | منفَّذ |

## 4. الإيماءات — القواعد الدقيقة

القواعد في `GestureEngine` (محاية للمنصة) ومُختبَرة في `GestureEngineTest`:

| القاعدة | القيمة الافتراضية | السبب |
| --- | --- | --- |
| عتبة الحركة (slop) | 18 بكسل | أقل منها = نقر، لتفادي القفزات العرضية |
| قفل المحور | يُحسم عند تجاوز العتبة ولا يتغير | سحب مائل قليلًا لا يحوّل التخطي إلى تغيير صوت |
| مدى التخطي للسحب الكامل | 120 ثانية | يكفي لملف 40 دقيقة دون دقة مفرطة |
| مناطق النقر المزدوج | < 34% رجوع · > 66% تقديم · الباقي تشغيل/إيقاف | تقسيم MX Player المألوف |
| السحب الرأسي | نصف أيسر = سطوع، نصف أيمن = صوت | إبهام اليد اليمنى للصوت |
| **الدلتات** | **تراكمية بين الأحداث** (`-(y - lastY)/height`) | **تطبيق دلتا من بداية الإيماءة في كل حدث يجعل السطوع يهرب** |

> العيب الأخير كان موجودًا في النسخة السابقة (`changeBrightness(-totalY / height)` داخل
> `onScroll`) وأُصلح بتمرير `GestureResult.delta()` التراكمي-بين-الأحداث؛ الاختبار
> `verticalDragOnTheLeftChangesBrightnessIncrementally` يثبّته.

**إيماءات معطّلة أثناء القفل** (`setLocked(true)`): كل شيء ما عدا زر «فك القفل».

## 5. المسارات والترجمة

| # | المتطلب | الحالة |
| --- | --- | --- |
| S1 | سرد المسارات الصوتية بلغة/تسمية | منفَّذ |
| S2 | التبديل بين المسارات الصوتية | منفَّذ (عبر `setPreferredAudioLanguage`) |
| S3 | ترجمة مصاحبة بالاسم (`.srt/.ass/.ssa/.vtt/.ttml/.sub`) | منفَّذ |
| S4 | اختيار ملف ترجمة يدويًا (`ACTION_OPEN_DOCUMENT`) | منفَّذ |
| S5 | حجم/لون/حافة الترجمة | منفَّذ عبر `SubtitleStyle` → `CaptionStyleCompat` |
| S6 | إزاحة زمنية للترجمة (±30 ث) | النموذج جاهز (`SubtitleStyle.offsetMs`)، الواجهة مؤجلة |
| S7 | ترميز نصي غير UTF-8 (مثل Arabic-1256) | غير منفَّذ — مُجدول |

**قاعدة الحجم:** نسبة من ارتفاع العرض (3%–12%) لا نقاط مطلقة، حتى تبقى الترجمة مقروءة
في PiP وعلى الأجهزة اللوحية. الخطوات: `SIZE_STEP = 0.018`.

## 6. العرض

- **نسبة العرض:** Fit / Fill / Zoom (+ 16:9 وOriginal في القائمة).
- **القفل:** إخفاء كل الضوابط مع زر فك واحد في المنتصف.
- **الاتجاه:** قفل اختياري على الاتجاه الحالي.
- **PiP:** عند الضغط على Home أثناء التشغيل (`onUserLeaveHint`) أو من القائمة؛ يُخفي الضوابط
  ويعيد بناء `GestureEngine` بحجم النافذة الجديد. يتطلب API 26 و`supportsPictureInPicture`.

## 7. الأخطاء — ما يراه المستخدم

لكل `PlayerErrorCode` إجراء محدد (`Recovery`)، فلا توجد رسالة «حدث خطأ» عامة:

| الخطأ | الرسالة/الإجراء |
| --- | --- |
| `SOURCE_NOT_FOUND` | «لم يعد مصدر الفيديو متاحًا» + إغلاق (بطاقة أُزيلت) |
| `DECODER_INIT_FAILED` | إعادة محاولة تلقائية واحدة، ثم اقتراح فك تشفير برمجي |
| `DECODER_UNSUPPORTED` | «لا يوجد مفكك لهذا الترميز» + معلومات الفيديو |
| `DRM_LICENSE_FAILED` | إعادة محاولة الترخيص |
| `DRM_DEVICE_NOT_SECURE` | «الجهاز لا يوفر مسار عرض آمنًا لهذا المحتوى» |
| `NETWORK_TIMEOUT` | تلميح اتصال + إعادة محاولة |
| `CACHE_IO_ERROR` | تعطيل التخزين المؤقت والمتابعة |

## 8. سهولة الوصول (Accessibility)

| المتطلب | التنفيذ |
| --- | --- |
| أهداف لمس ≥ 48dp | `@dimen/touch_target` في التخطيط |
| `contentDescription` لكل زر أيقوني | منفَّذ في `activity_video_player.xml` |
| TalkBack: الضوابط لا تختفي تلقائيًا أثناء التركيز | **غير منفَّذ** — مطلوب: تعطيل `scheduleHideControls()` عند `AccessibilityManager.isTouchExplorationEnabled()` |
| تباين النص | نص أبيض على تدرّج (scrim) علوي/سفلي |
| إيماءات بديلة | أزرار ⏪/⏩ تعادل السحب الأفقي؛ `GestureConfig` يسمح بتعطيل الإيماءات كليًا |
| حجم الترجمة | حتى 12% من ارتفاع الشاشة (≈ 4× الافتراضي) |
| وضع داكن/فاتح | المشغل داكن دائمًا (سلوك مقصود)، وبقية التطبيق تحترم `ThemedActivity` |

## 9. نماذج UX نصية (Wireframes)

**حوار الاستئناف**
```
┌───────────────────────────────┐
│ متابعة التشغيل؟               │
│ المتابعة من 12:34؟            │
│  [ البدء من جديد ] [ متابعة ] │
└───────────────────────────────┘
```
يظهر فقط إذا `ResumePolicy` قال RESUME؛ الملفات التي شوهدت > 95% أو بقي منها < 30 ث
تُفتح من البداية بلا حوار.

**مؤشر الإيماءة**
```
        ┌──────────────┐
        │  +00:30 12:46│   ← تخطي
        └──────────────┘
        ┌──────────────┐
        │  السطوع 62%  │   ← سحب رأسي أيسر
        └──────────────┘
        ┌──────────────┐
        │  الصوت 40%   │   ← سحب رأسي أيمن
        └──────────────┘
```
يختفي بعد 900 مللي ثانية (`OVERLAY_TIMEOUT_MS`)، والضوابط بعد 3200 مللي ثانية.

**إحصاءات التشغيل** (قائمة `⋮`)
